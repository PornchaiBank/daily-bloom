เชื่อม Google Sheets

ตั้งค่าครั้งแรกบนมือถือเครื่องนี้ แล้วเข้าสู่ระบบด้วย Google เพื่ออ่านและบันทึกข้อมูลจริง

Client ID ไม่ใช่รหัสผ่าน ไม่ต้องใส่ Client Secret

ตั้งค่าใน Google Cloud ครั้งแรก
  1. เปิด Google Sheets API และตั้งค่า OAuth consent screen
  2. สร้าง OAuth Client ID แบบ Web application
  3. เพิ่ม Authorized JavaScript origin:
  4. หากแอปอยู่ในโหมด Testing ให้เพิ่มอีเมลของคุณเป็น Test user
  5. ใช้บัญชี Google ที่มีสิทธิ์แก้ไขชีตนี้
เปิด Google Cloud ↗
